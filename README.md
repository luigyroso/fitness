# Tu Entrenamiento

A mobile-first workout tracker built as a single-page static website. Guides you through Push, Pull, and Legs routines with exercise GIFs, rest timers, and progress tracking.

## Features

- **Push / Pull / Legs** split with warm-up phases and main workout
- **Exercise GIFs** auto-fetched from ExerciseDB with local caching
- **Rest timer** with circular countdown between exercises
- **Progress persistence** — resume an interrupted workout within 6 hours
- **Apple-inspired UI** — clean, responsive design optimized for mobile

## Live Site

[https://luigyroso.github.io/fitness/](https://luigyroso.github.io/fitness/)

## Tech

Pure HTML, CSS, and vanilla JavaScript. No build step, no dependencies. Uses `localStorage` for state and GIF caching.
